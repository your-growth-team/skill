# About this bundled copy

This is the UI/UX Pro Max guideline file as installed in the author's workspace. The upstream project also ships a `scripts/search.py` tool and a CSV design database (styles, palettes, font pairings). Those files were not present in the installed copy, so they are not bundled here. The CRO auditor only needs the rules in ui-ux-pro-max.md (renamed from SKILL.md so it can ship inside this skill) (accessibility, touch, layout, typography, CTA hierarchy, icon discipline and the pre-delivery checklist).

To get the full database, install the upstream project: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT licence).
